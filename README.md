UK TV Search Tool 🎬🇬🇧
========================

Created by: Emily Rutherford

🔎 About
--------
The UK TV Search Tool is a user-friendly web application that allows you to:
- 🔍 Search for UK TV shows using the TVMaze API
- ⭐ Add your favourite shows to a Favourites list
- 🕰️ View your Search History and click to re-search
- 🌙 Switch between Light Mode, Dark Mode, and High Contrast Mode
- 🔔 Enjoy smooth animations and accessible ARIA notifications
- 📱 Experience full mobile responsiveness

📂 Folder Structure
--------------------
- `/index.html` → The main home page
- `/style.css` → All CSS styling (responsive and accessible)
- `/script.js` → JavaScript for search, favourites, history, and animations
- `/images/` → Logos, placeholder images (in WebP format)
- `/videos/` → Header background videos (MP4)
- `/404.html` → Custom error page for broken links
- `.htaccess` → Redirect rules for hosting (like 404 handling)
- `/backup-versions/` → *(Optional)* Backup copies of older JavaScript versions

🛠️ Technologies Used
----------------------
- HTML5
- CSS3
- JavaScript (ES6)
- TVMaze API
- ARIA roles for accessibility
- Responsive Web Design (RWD)
